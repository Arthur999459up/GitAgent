## Request

- **Operation:** `{{operation}}`

## Output contract

- `queries`: one to three concise literal code or content searches, ordered by expected value. Expand conceptual requests into likely APIs, identifiers, or project terminology; preserve exact names supplied by the user.
- `path_terms`: zero to four useful filename or path fragments.
- `symbols`: only identifiers the user explicitly asks to locate, explain, or analyze as symbols. A generic topic is not a symbol.

Do not include GitHub search qualifiers, prose explanations, duplicate values, or speculative terms unrelated to the request.
